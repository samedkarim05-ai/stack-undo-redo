How stacks work here

  1. Each edit saves the previous text state in the undo stack.
  2. Undo pops the most recent state from the undo stack.
  3. Redo pops a state from the redo stack and restores it.
  4. Making a new edit clears the redo stack.

LIFO: Last In, First Out — the newest saved state is used first.
